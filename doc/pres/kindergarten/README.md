# Kindergarten Robot Presentation 🤖👶

A fun and engaging reveal.js presentation about robots designed specifically for 4-year-old kindergarten children.

## 🎯 Audience
- **Age**: 4 years old (Kindergarten)
- **Duration**: 15-20 minutes
- **Format**: Interactive presentation with lots of visuals

## 📋 Presentation Overview

The presentation covers:

### 🏠 Robots at Home
- **Roomba vacuum cleaners** - The robot that cleans floors
- **Robot lawn mowers** - Robots that cut grass
- **Restaurant robots (Pudu Bellabot)** - Robots that serve food

### 🚗 Robot Cars
- **Tesla self-driving cars** - Cars that can drive themselves

### 🚀 Space Robots
- **Lunar rovers** - Robots living on the Moon
- **Mars rovers (Perseverance)** - Robots exploring Mars
- Why space exploration needs robots

### 🛠️ Our Robot
- **Eraccoon robot** - The robot from this repository
- How robots are built
- Skills needed to create robots

## 📁 Files

- `index.html` - Main presentation file (reveal.js)
- `photo-links.md` - Links to download required photos
- `README.md` - This file

## 🚀 Quick Start

1. **Download photos**: Follow instructions in `photo-links.md`
2. **Open presentation**: Open `index.html` in a web browser
3. **Navigate**: Use arrow keys, spacebar, or click to advance slides
4. **Present**: Engage kids with questions and encourage participation

## 🖼️ Photo Setup

The presentation uses placeholders for photos. To add real images:

1. Create an `images/` folder in this directory
2. Download photos using the links in `photo-links.md`
3. Replace placeholders in `index.html` with actual `<img>` tags

## 🎨 Design Features

### Kid-Friendly Design
- **Large fonts** (48px+) for easy reading
- **Comic Sans MS** font for playful feel
- **Lots of emojis** to maintain attention
- **Bright colors** and engaging visuals
- **Simple language** appropriate for 4-year-olds

### Interactive Elements
- **Questions** throughout the presentation
- **Imagination prompts** ("What would your robot do?")
- **Recognition activities** (pointing out familiar robots)

## 🎯 Learning Objectives

After this presentation, children should be able to:
- Identify robots they might see in everyday life
- Understand that robots help people with tasks
- Know that robots explore space for us
- Recognize that building robots requires different skills
- Feel excited about robots and technology

## 💡 Presentation Tips

### Before Starting
- Test the presentation on the actual device you'll use
- Have backup images ready in case of technical issues
- Prepare simple explanations for curious questions

### During Presentation
- **Encourage participation**: "Have you seen this robot before?"
- **Use gestures**: Point to images and act out robot movements
- **Keep it interactive**: Ask questions every few slides
- **Be enthusiastic**: Your excitement will be contagious!
- **Go at their pace**: Some slides might spark lots of discussion

### After Presentation
- **Activity ideas**: Draw your dream robot, build with blocks
- **Discussion**: What robots would help at home/school?
- **Connection**: Point out robots in their daily environment
